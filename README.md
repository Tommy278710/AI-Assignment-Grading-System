# 🎓 AI Assignment Grading System

An AI-powered academic assignment grading system designed to assist lecturers in evaluating student submissions using customizable marking guides, rubrics, and intelligent automated assessment workflows.

The system aims to reduce the time and effort required for manual grading while providing a structured and consistent approach to evaluating student assignments.

---

## 🚀 Project Overview

Manual assignment grading can be time-consuming, especially when lecturers need to evaluate a large number of student submissions using detailed marking schemes.

The **AI Assignment Grading System** explores how Artificial Intelligence and Large Language Models (LLMs) can be used to support the academic assessment process.

The platform allows lecturers to define or generate marking guides and rubrics, while students can submit their assignments for evaluation.

The system analyzes submitted work against the specified assessment criteria and produces structured grading results that can assist lecturers in reviewing student performance.

> **Note:** The system is designed as an AI-assisted grading tool. Final academic decisions and grades should remain under the supervision of qualified educators.

- Add and manage courses
